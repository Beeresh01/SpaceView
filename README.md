🚀 SpaceView

SpaceView is an interactive 3D deep-space and Solar System explorer built as a single-page web application.

Explore planets, dwarf worlds, moons, spacecraft, deep-space objects, missions, and educational science content through an interactive Three.js experience.

🌌 Features

🪐 Interactive 3D Solar System

☀️ Sun and all 8 planets

◈ Dwarf planets — Ceres, Pluto, Haumea, Makemake and Eris

🌙 Moon Explorer with major planetary moons

☄️ Asteroid Belt, Kuiper Belt and Oort Cloud

🚀 Voyager 1, Voyager 2 and New Horizons

🎮 Interactive cockpit / flight mode

🛰️ Mission Control with playable mission steps

🔭 Deep Space objects including galaxies and nebulae

🔎 Deep Space Search

📚 Educational information for space objects

🧠 Interactive quiz system

🏆 Achievements and XP

⚡ Simulation speed controls

✨ Atmospheric, lighting and graphical surface effects

🌌 Cinematic deep-space visuals

⌨️ Keyboard shortcuts

💾 Local browser persistence

📱 Responsive interface

SpaceView is intentionally kept as a simple single-file project so it can be easily explored, modified and deployed using GitHub Pages.

▶️ Run Locally

Clone the repository:

git clone https://github.com/Beeresh01/SpaceView.git
cd SpaceView

Open index.html in a browser.

For the best experience, run it through a local web server:

python -m http.server 8000

Then open:

http://localhost:8000

🌐 Deployment

SpaceView is designed to work with GitHub Pages.

After pushing the repository to GitHub:

Open the repository.

Go to Settings → Pages.

Under Build and deployment, select Deploy from a branch.

Select the main branch and / (root).

Click Save.

GitHub will provide the published Pages URL.

🎯 Project Goal

SpaceView was created as an educational and interactive visualization project that combines 3D graphics, astronomy, exploration mechanics and learning content into a single browser-based experience.

⚠️ Notes

Some graphical textures and visual assets are loaded from public Three.js example resources, so an internet connection may be required for the full visual experience.

SpaceView is an educational visualization and does not attempt to reproduce physically accurate spacecraft flight dynamics.
